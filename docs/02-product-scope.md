# 产品范围 — 选举前的“选情情报面板”

- 日期：2026-11-10
- 对应技术栈：`01-tech-stack.md`
- 阶段：2026-11 → 2027-04（首轮 4/18，次轮 5/2）

## 1. 定位

**不是**结果站，也**不是**“预测谁赢”的单一结论。

**是**一个持续更新的情报面板：

1. 收集法语媒体、非法语媒体、社交网络、论坛、民调、预测市场的公开信息；
2. 把“谁被谈论、被如何谈论、在哪些议题上、声量多大”结构化；
3. 用透明的方法给出候选人/政党的**多维度评分**与**胜率区间**；
4. 用地图展示基线、投影、关注度与竞选活动；
5. 所有数字可追溯、可拆解、可回测。

### 非目标

- 不做用户评论、投稿、社区。
- 不做付费墙绕过、批量抓取登录内容。
- 不做“全国情绪”单一指数。
- 不在投票静默期发布民调/预测。

## 3. 核心指标定义

所有指标都带：`as_of` 时间、样本量、来源数、置信度。

### 3.1 民调

- `poll_avg_c`：候选人 c 的首轮意向均值。
- 聚合：时间衰减（半衰期 21 天）+ 样本权重 `sqrt(n)` + 机构房效应 + 政党合并。
- 输出：均值、80% 区间、趋势（7 天/30 天）、纳入的民调列表。
- 只在民调发布后 1 小时内入库；人工复核后才进入聚合。

### 3.2 市场

- `market_prob_c`：去水后的隐含概率。
- 平台：Polymarket、Kalshi、Metaculus；Betfair 有账户再加。
- 去水：`p_i = odds_i^{-1} / Σ odds_j^{-1}`；按流动性加权。
- 记录时间序列，不覆盖历史。

### 3.3 媒体声量

- `share_of_voice_c`：候选人/政党在窗口期内被提及的文章占比。
- 来源加权：全国媒体 > 地方媒体 > 聚合/转载；同一 URL 只计一次。
- 窗口：24h / 7d / 30d。
- 展示：总量、占比、环比、来源分布、Top 文章。

### 3.4 社交关注度

- `social_attention_c`：去重作者数 + 互动量（点赞/转发/回复的加权和）。
- 平台：X（核心账号）、Bluesky、Mastodon、YouTube（可选）。
- 过滤：bot score、账号年龄、粉丝阈值、重复文本。
- **不展示单条未核实帖子作为“民意”**；只做聚合与样本示例。

### 3.5 立场分布

- `stance ∈ {support, oppose, neutral, unclear}`，针对“文章/帖子 → 实体”。
- 由 LLM 分类 + 关键词规则 + 人工抽检；置信度低于阈值归入 `unclear`。
- 聚合：`stance_balance = (support - oppose) / (support + oppose + neutral)`。
- 必须显示样本量与分类准确率抽检结果；不称其为“全国民意”。

### 3.6 议题显著性

- 议题体系（v1）：经济/购买力、移民/安全、退休/社保、医疗、教育、气候/能源、欧洲/外交、制度/民主、司法、文化/身份。
- `topic_salience_{c,t}`：候选人 c 在议题 t 上的提及占比。
- 用途：候选人页的“议题画像”、首页的“本周议题”。

### 3.7 综合评分

```text
composite_c = 100 * (
    0.45 * poll_norm_c +
    0.20 * market_norm_c +
    0.15 * media_norm_c +
    0.10 * social_norm_c +
    0.10 * elite_norm_c
)
```

| 分量 | 归一化 |
|---|---|
| `poll_norm` | `poll_avg_c / max(poll_avg)` |
| `market_norm` | `P(win)` 或 `P(runoff)`（页面可切换） |
| `media_norm` | 声量百分位 |
| `social_norm` | 关注度百分位 |
| `elite_norm` | 背书/parrainages/党内支持，按最大值归一 |

- 政党版权重：poll 0.55、market 0.20、media 0.10、social 0.05、elite 0.10。
- 页面展示每个分量与贡献；提供“权重模拟器”。
- **权重可调整**：默认权重来自服务端；用户可在页面上拖动 5 个滑块，实时重算，权重写入 URL query（如 `?w=45,20,15,10,10`）和 `localStorage`，可分享链接、可一键恢复默认。
- 自定义权重只在前端计算，不写回 D1；服务端只缓存默认权重版本。
- 默认权重公开在方法论页；任何默认调整记入 changelog。
- **composite 不是胜率**；胜率单独由贝叶斯模型给出。

### 3.8 置信度

```text
confidence = 0.4 * min(1, polls_30d / 5)
           + 0.3 * market_liquidity_score
           + 0.3 * sample_quality_score
```

展示为 `low / medium / high`，并给出原因（民调少、市场流动性低、样本小）。

## 4. 预测模型 v1（Python 容器）

### 4.1 民调聚合（分层）

- 潜变量 `theta_{c,t}`：候选人 c 在 t 日的真实首轮得票率。
- 观测：`y_{p,c} ~ Normal(theta_{c,t} + house_p + bias, se_{p,c})`
  - `se = sqrt(p(1-p)/n) * design_effect`，`design_effect ≈ 1.2–1.5`
- 时间：随机游走 `theta_{c,t} = theta_{c,t-1} + N(0, sigma)`，`sigma` 约 0.2–0.5 pt/周。
- 房效应：`house_p ~ Normal(0, 1)`，按历史偏差收缩。
- 政党合并：NUPES/LFI/PS/PCF/EELV、RN/UDR、LR、Renaissance/Horizons/Modem 等映射到稳定 ID，保留子标签。
- 约束：`sum_c theta_c ≈ 100`（用 log-ratio 或 softmax 参数化）。

### 4.2 市场融合

- 将市场概率作为额外观测：`logit(p_market) ~ Normal(logit(p_model), tau)`。
- `tau` 按平台流动性/历史校准；默认市场权重 20–30%。
- 市场只影响胜率/次轮，不直接改首轮得票率。

### 4.3 次轮与胜率

- 从后验抽 20k–50k 组首轮得票。
- 前二进入次轮；转移矩阵来自：
  - 2022/2024 次轮实际转移；
  - 民调中的“第二选择”数据；
  - 政治阵营距离（左/右/中间）。
- 输出：`P(win)`、`P(runoff)`、次轮对决概率矩阵、80% 区间。

### 4.4 席位（后续）

- 立法选举：全国 swing + 选区局部弹性 + 现任者优势 + 2024 基线 + 三角/退选规则。
- 输出席位分布与 `P(majority)`；2027 年 3 月后再做。

### 4.5 回测

- 2017、2022 总统；2022、2024 立法。
- 指标：Brier、log loss、校准曲线、按省误差。
- 每次预测记录 `model_version`、`inputs_hash`、`seed`，可复现。
- 方法论页公开：数据截止、权重、假设、已知缺陷、版本变更。

## 5. 地图

### 5.1 图层

| 图层 | 数据 | 类型 | 默认 |
|---|---|---|---|
| 2022/2024 基线 | 内政部/data.gouv | 真实 | 开 |
| 2027 首轮投影 | 全国民调 + 地区 swing + 人口 | 模型 | 关（需主动切换） |
| 媒体关注度 | 地方/全国媒体提及 | 观测 | 关 |
| 社交关注度 | 按省聚合（有地理位置时） | 观测 | 关 |
| 竞选活动 | 访问/集会/背书 | 人工 | 关 |
| 立法席位投影 | 577 选区 | 模型 | 后续 |

### 5.2 交互

- 省/大区 hover：名称、指标值、样本量、区间。
- 点击下钻：省内 Top 候选人/政党、来源列表。
- 时间滑块：周/月变化。
- 图例明确“实际 / 模型估计 / 样本不足”。
- 提供表格视图与 CSV 导出。

### 5.3 诚实性规则

- 总统民调是全国性的，省级投影是**模型**，不是省级民调。
- 样本不足的省显示灰色，不做插值伪装。
- 投影层必须显示不确定性（区间或透明度）。
- 不在地图上做“胜负已定”的断言。

## 6. 信息架构

```text
/                     总览：评分榜、趋势、最新民调、市场、地图预览
/candidats/[slug]     候选人：评分拆解、民调、声量、立场、议题、信息流
/partis/[slug]        政党：同上 + 候选人列表 + 地区强度
/sondages             民调表 + 聚合曲线 + 方法论入口
/marches              市场概率 + 平台对比 + 流动性
/carte                地图（图层/时间/下钻）
/fil                  信息流（来源/语言/议题/实体/立场筛选）
/methodologie         方法、权重、回测、更正记录
/a-propos             项目说明、中立性、数据来源、联系方式
/admin                Access 保护：民调复核、实体合并、来源健康
/en/..., /zh/...      对应英文/中文
```

### 6.1 首页模块

1. 一句话现状（自动生成，人工可改）：`截至 X 日，A 领先，B 上升，C 稳定`。
2. 评分榜（Top 8–10，可切换 composite / P(win)）。
3. 趋势图（30/90 天）。
4. 最新民调（3 条）。
5. 市场概率（Top 5）。
6. 地图预览（基线/投影切换）。
7. 今日焦点（Top 5 文章/观点）。
8. 数据新鲜度与来源数。

### 6.2 候选人页模块

- 头部：姓名、政党、照片、状态（已宣布/潜在/退出）、评分。
- 评分拆解（5 个分量 + 贡献）。
- 民调趋势 + 区间。
- 市场概率。
- 声量与立场（样本量、来源分布）。
- 议题画像。
- 相关文章/帖子（按时间）。
- “数据截止/方法”链接。

## 7. 三语策略

| 内容 | 法语 | 英语 | 中文 |
|---|---|---|---|
| UI | 原文 | 全量 | 全量 |
| 候选人/政党简介 | 人工 | 人工/AI + 校对 | 人工/AI + 校对 |
| 民调/市场/评分 | 数字 + 法语标签 | 翻译标签 | 翻译标签 |
| 新闻标题/摘要 | 原文 | 不翻译（保留法语，附原文链接） | 不翻译（保留法语，附原文链接） |
| 方法论 | 法语全文 | 全文 | 全文（可稍简） |

- 中文范围：**UI + 关键页面**（首页、候选人/政党页、地图、民调、市场、方法论、关于）。新闻流保留法语原文，避免机器翻译成本与误译。
- 关键页面的人工/AI 翻译需校对；术语表统一译名。
- 自动翻译标注“Traduction automatique / Auto-translated / 自动翻译”。
- `hreflang` + 分语言 sitemap；语言切换保留当前路径。
- 日期/数字用 `Intl`；法语用 `fr-FR`，中文用 `zh-CN`。

## 8. 编辑与中立性

- 不背书任何候选人/政党。
- 所有政党使用同一套指标与窗口；不因阵营调整权重。
- 评分变化超过阈值时，首页显示“为什么变了”（民调/市场/声量）。
- 更正公开记录；重大更正单独发帖。
- AI 生成内容显式标注；不自动发布结论。
- 资金来源/合作方披露（若有）。
- 静默期：投票前一天与投票日隐藏民调/预测模块，只保留官方事实与结果。

## 11. 验收标准（v1）

- 首页 3 秒内可交互（4G，缓存命中）。
- 任一评分可点开看到 5 个分量与数据截止时间。
- 任一民调可追溯到原始 PDF/notice。
- 任一文章可追溯到来源与抓取时间。
- 地图基线/投影切换明确标注“实际/模型”。
- 三语页面无硬编码中文/法文混杂。
- 月账单 < $50，X reads < 4,000。
- 静默期开关一键生效。
