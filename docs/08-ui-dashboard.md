# 界面重构：数字大屏 / Palantir 风格

- 日期：2026-11-10
- 目标：从长页面滚动改为**固定视口、面板化、可交互**的指挥中心
- 范围：首页完全重构；其他页面保留内容，但套进深色应用壳

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| 不滚动整个页面 | `body` / `html` 固定 `100dvh`，`overflow: hidden` |
| 面板内部滚动 | 每个 `.panel` 独立 `overflow: auto` |
| 一眼看到关键信息 | 6 个面板：排名、地图、详情、媒体热度、信息流、市场 |
| 点击即联动 | 点候选人 → 详情；点地图省份 → 详情；点热度 → 候选人 |
| 数字优先 | 等宽字体、表格、微图表、状态点 |
| 深色控制台 | 深蓝黑背景、细网格、青色高亮、琥珀警示 |

## 2. 应用壳

```text
┌──────────────────────────────────────────────┐
│ 顶栏：品牌 / LIVE / 时钟 / 语言 / DÉMO        │
├──────┬───────────────────────────────────────┤
│ 图标 │ 主工作区（fullscreen 或文档面板）      │
│ 导航 │                                       │
├──────┴───────────────────────────────────────┤
│ 状态栏：SYSTEM ONLINE / D1 / RSS / UTC+1      │
└──────────────────────────────────────────────┘
```

- 顶栏 48px，状态栏 28px，左导轨 72px。
- 桌面端无 body 滚动；移动端隐藏导轨，顶部出现横向导航，`.dash` 内部滚动。
- 内容页（方法论、关于、候选人、民调、市场）使用深色外壳 + 浅色文档面板，保持可读性。

## 3. 首页 Dashboard

```text
┌────────────┬──────────────────────┬────────────┐
│ 排名        │ 地图                 │ 详情        │
│ 280px      │ flex                 │ 340px      │
├────────────┼──────────────────────┼────────────┤
│ 媒体热度    │ 信息流               │ 市场        │
│ 220px 高    │ 220px 高             │ 220px 高    │
└────────────┴──────────────────────┴────────────┘
```

### 排名面板

- 按综合分 / 民调 / 市场排序。
- 搜索框过滤候选人和信息流。
- 每行：排名、政党色点、姓名、政党、综合分、民调/市场、12 周微趋势。
- 齿轮按钮打开**权重面板**：5 个滑块，实时重算排名；URL `?w=` + localStorage 持久化。

### 地图面板

- 深色 SVG 地图，96 个本土省，真实 2022 首轮结果。
- 政党色使用暗色高亮调色板。
- hover 顶部浮层显示省份/领先者；点击联动详情面板。
- 缩放 +/−/重置。
- 底部 ticker：最新标题 + 文章数 + 来源数。
- 2027 投影按钮暂时禁用。

### 详情面板

- `Candidat`：政党、状态、综合分、置信度、5 个分量条、12 周趋势、简介、档案链接。
- `Département`：省份、大区、领先者、得票率、投票率、Top 6 结果、地图链接。
- 点击排名或地图自动切换模式。

### 媒体热度

- 7 天提及量，横向条形图；点击候选人联动详情。
- 数据来自 `media_momentum`，不是民意。

### 信息流

- 最新 50 条选举相关文章；来源/议题下拉筛选；搜索框联动。
- 每行：时间、标题、来源、议题；点击外链。
- 内部滚动，不撑高页面。

### 市场

- 真实 D1 市场；为空时显示三个连接器状态（Kalshi / Polymarket / Metaculus）。
- 不伪造概率。

## 4. 技术实现

- `Base.astro`：深色应用壳，`fullscreen` 开关。
- `Dashboard.svelte`：面板布局、选择状态、排序、搜索、权重、时钟。
- `MapCanvas.svelte`：深色地图、选择、缩放、hover、图例。
- `MapWorkspace.svelte`：`/carte` 全屏深色地图 + 省份详情。
- `lib/colors.ts`：暗色政党调色板。
- `Clock.svelte`：Europe/Paris 实时时钟。
- `global.css`：`.panel`、`.dash`、`.ticker`、滚动条、网格背景。
- 数据仍由 `DashboardPage.astro` 在服务端从 D1 读取，传给 Svelte。

## 6. 已知限制

1. 2027 投影图层未启用（等模型）。
2. 地图只有本土 96 省；海外省未画。
3. 市场为空时只显示连接器状态。
4. 方法论/关于/民调/市场/候选人仍是浅色文档面板；首页和 `/carte` 已是全屏深色，后续可逐页改造。
5. 移动端是“内部滚动的单列大屏”，不是真正的移动优先布局。
6. 没有命令面板（Ctrl+K）；搜索目前只过滤排名和信息流。
7. 权重只影响前端展示，不写回 D1；这是有意为之。
